# Plataforma de Eventos e Inscripciones

API REST desarrollada para el proyecto de Backend II.

## Temática

El proyecto consiste en una plataforma de eventos e inscripciones donde los usuarios podrán consultar eventos y, en futuras etapas, registrarse e inscribirse.

También se incorporarán organizadores y administradores con diferentes permisos.

## Tecnologías

- Node.js
- Express
- JavaScript
- MongoDB
- Mongoose
- dotenv
- npm
